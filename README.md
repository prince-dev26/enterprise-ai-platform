# Enterprise AI Knowledge Platform

A production-ready AI-powered SaaS platform where organizations can securely upload documents, manage workspaces, and chat with their knowledge base using Retrieval-Augmented Generation (RAG).

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- PostgreSQL
- Redis

### AI
- OpenAI / Claude / Gemini
- pgvector
- LangGraph (later)

### DevOps
- Docker
- GitHub Actions
- AWS
